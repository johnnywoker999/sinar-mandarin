# SINAR 中文通 — 產品提案（網頁版）

面向印尼市場的「中文學習 × AI 輔助 × 職涯商機」一站式平台的客戶提案頁。

## 內容

- **市場機會**：中資企業落地、跨境賣家、旅遊三股驅動力（含來源數據）
- **痛點與缺口**：三個結構性缺口、以及被實證推翻的原始假設
- **產品方案**：八個功能模組與兩個首發情境包
- **運作閉環**：核心學習循環（測評→課程→AI 陪練→場景任務→認證→就業）＋ 三條業務閉環（電商／企業 B2B／旅遊導遊）
- **獲利模式**：五條收入線、定價定位、單位經濟與分階段收入結構
- **競爭壁壘**：五道壁壘與競品對照矩陣
- **推進路線**：三階段里程碑與驗收線
- **風險與合規**：技術風險與印尼上線前合規前置

## 使用方式

單一 HTML 檔、無需建置，直接用瀏覽器開啟 `index.html` 即可。

- 桌面：左側固定章節導航（滾動自動定位）
- 手機／平板：底部橫條導航、單欄垂直排列
- 支援列印（已處理深色背景與進場動畫的列印樣式）

## 資料來源

所有市場數字取自 5 份市場研究報告（市場競品／就業職涯／旅遊留學／電商跨境／AI 技術與合規），逐項附來源網址與年份。
